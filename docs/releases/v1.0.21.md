## 中文

GameCase 1.0.21 — GitHub 账号更名与链接迁移

本版本由 whodaregg 维护，修改日期：2026-11-17。基于 GameCase / LiveContainer，保留原作者及第三方的版权与许可通知。

- GitHub 仓库迁移到 https://github.com/whodaregg/GameCase 。更新软件“关于”页、离线许可资料中的仓库及对应源码下载入口、README、构建说明与发布资料。
- 更新正式版及 Nightly 更新源的仓库、下载和图片地址，清理指向已移除游戏截图的失效链接。保留应用标识和更新源标识，继续支持在原安装上升级。
- 更新源生成器能够根据源文件记录的仓库地址迁移链接，同时保留上游作者归属，避免把原作者名称替换成当前仓库名称。
- 保留中英双语更新说明、独立 SideStore / AltStore 签名支持，以及已有金手指、存档备份、性能和诊断功能；不内置 SideStore。

验证范围：更新源地址迁移、原作者归属保留和既有 Python 回归测试；macOS 存储/金手指回归及 Xcode 归档；发布前检查 IPA 版本、内置许可链接、对应源码与下载地址一致性。

源码与构建：[本版本源码包](https://github.com/whodaregg/GameCase/releases/download/v1.0.21/GameCase-source.tar.gz)、[固定 tag](https://github.com/whodaregg/GameCase/tree/v1.0.21)、[构建与安装说明](https://github.com/whodaregg/GameCase/blob/v1.0.21/docs/BUILDING.md)。历史标签和对应源码保留；1.0.20 安装包下架。如需软件内的新地址，请升级到本版本。依赖的历史溯源边界继续见许可审查记录。

## English

GameCase 1.0.21 — GitHub account rename and link migration

Maintained by whodaregg; modification date: 2026-11-17. Based on GameCase / LiveContainer, retaining the original authors' and third parties' copyright and license notices.

- Moves the GitHub repository to https://github.com/whodaregg/GameCase . Updates the app's About page, repository and corresponding-source links in its offline legal materials, README, build instructions and release documentation.
- Updates repository, download and image URLs in stable and Nightly update feeds, and removes broken links to removed game screenshots. Keeps the application and feed identifiers so existing installations can continue to upgrade.
- Makes feed generation migrate repository URLs using the source's recorded website while preserving upstream attribution, rather than replacing the original authors' names with the current repository name.
- Retains bilingual release notes, signing support through external SideStore / AltStore, and the existing cheat, save-backup, performance and diagnostic features. SideStore is not bundled.

Validation scope: feed URL migration, preservation of upstream attribution and existing Python regressions; macOS storage/cheat regressions and Xcode archive; pre-publication checks of the IPA version, embedded legal links, corresponding source and download URLs.

Source and build materials: [source bundle for this version](https://github.com/whodaregg/GameCase/releases/download/v1.0.21/GameCase-source.tar.gz), [fixed tag](https://github.com/whodaregg/GameCase/tree/v1.0.21), [build/install instructions](https://github.com/whodaregg/GameCase/blob/v1.0.21/docs/BUILDING.md). Historical tags and corresponding source are retained; the 1.0.20 installation package is withdrawn. upgrade to this version for the new in-app addresses. Previously documented limits on dependency provenance remain in the license review.
