GameCase 1.0.16：移除内置 SideStore，修复导入、存档与发布流程。

- 仅提供普通版 GameCase.ipa，移除内置 SideStore 及其启动、分享和续签入口；继续支持外部 SideStore / AltStore 签名和证书导入。
- 修复压缩包路径越界、链接越界和解压失败仍报告成功的问题，阻止不完整存档继续进入替换流程。
- 移除云存档配置时清理所有已知游戏容器的书签；清理失败保留关闭记录并报告错误。
- 数据包和存档替换增加失败回滚，文件复制正确报告读写错误。
- 修正仓库下载和更新源地址，nightly 使用本次构建的实际版本与 IPA 大小。

安装与升级：
- 本 IPA 需自行使用开发者证书签名；免 JIT 使用的导入证书须与本体签名同团队。
- 从旧内置版升级前，请先准备独立的续签工具。以相同 App 标识覆盖安装可保留数据；升级不会主动删除旧 SideStore 数据目录。
- 升级后不再提供 GameCase 内的 SideStore 续签入口。

本版已通过自动回归测试与 Xcode 构建验证。尚未进行 iOS 真机测试。
