GameCase 1.0.19 adds save-backup management, storage preflight checks and diagnostic summaries.

- Open Save Backups from a game's settings to create, restore, export or delete backups for the selected data container. Restoring first backs up the current save, then replaces the complete save set. Backups can also recover a missing save directory. Pending and linked backup directories are excluded; deletion needs confirmation. Keep the game closed while managing saves.
- Save, Mod and data-pack imports check free capacity against their temporary-copy and backup requirements. Archive extraction checks uncompressed sizes during its existing validation pass and reports insufficient space before writing. Estimates include a small overhead allowance; unsupported capacity queries fall back to normal I/O error handling and rollback.
- Export a diagnostic JSON summary from the game log viewer. It includes versions, known NSO Build IDs, data-file sizes, cheat-file compatibility counts and fixed error categories inferred from the previous log. It does not include raw logs, file paths, certificates, preferences or save contents. Unknown Build IDs remain unknown; log categories are diagnostic hints, not proof of current game behavior.
- Save-size calculation runs off the UI thread. Save import reuses its current-save snapshot for backup preparation.

Validation adds production-backend checks for backup restore and rollback, missing saves, exact backup-root preservation, path containment, selective deletion, storage estimation and diagnostic export. Portable archive tests simulate insufficient capacity and verify that no extraction writes occur. Existing storage, performance, cheat, packaging and release-source regressions remain enabled.
