GameCase 1.0.17 improves cheat-file compatibility and makes version mismatches visible.

- Import UTF-8 BOM and BOM-marked UTF-16 files. Normalize same-line headers and packed hexadecimal words without changing cheat addresses or values.
- Keep duplicate and case-distinct entries, preserve significant name spaces, and save independent selections using the current engine's state keys.
- Prevent rapid toggle changes from losing other selections. Preserve unknown guest state keys.
- Import extracted Atmosphere folders for the current title. Skip conflicting files for the same Build ID instead of silently overwriting them.
- Back up replaced files and selections in Documents/cheat-backups/. Changed code needs selecting again; text and state are committed together with rollback.
- Show NSO Build IDs read from game metadata, mismatched files, malformed code lines, and previous-run log excerpts.
- Add a global off switch that also stops master entries on the next game launch.

The game IPA supplies the cheat engine. Unsupported opcodes, wrong game addresses and iOS signed-code-page restrictions cannot be fixed by a GameCase UI change. No measured in-game success percentage is claimed.
