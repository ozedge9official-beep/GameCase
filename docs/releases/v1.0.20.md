GameCase 1.0.20 — 许可资料、对应源码与素材整理

本分叉由 whodaregg 维护；修改日期：2026-11-17。基于Tiaoge-tou/GameCase 与 LiveContainer，保留原作者和贡献者归属；本版本不是上游官方发行。

- 设置新增“许可证与源代码”：AGPL、第三方许可与版权通知（含 litehook 的外部 Apple ABI 头文件）可离线阅读，随 IPA 分发。
- 安装包旁提供 GameCase-source.tar.gz、完整主许可证、第三方通知和 SHA256SUMS。源码包包含本版本代码、固定 litehook/OpenSSL 材料、校验过的 OpenSSL 3.3.3 原始源码，以及构建/安装说明。发布流程校验 IPA、源码包和目标提交的源码 tree 一致。
- 核实 Feather 使用的独立 Zsign 子模块为 MIT，保留原版与该子模块的完整许可通知，更新来源说明。
- 移除两个授权未核实的内置游戏封面及相关 README 游戏截图。游戏自带和自定义封面保留；联网获取改为设置页手动操作，导入或浏览库时不自动访问商店。联网图片及用户提供的内容仍需相应使用权，开源代码许可不授予游戏素材权利。
- 后台锁文件处理改用 SDK F_GETPATH 与最小的当前进程枚举接口，移除不再需要的复制 Apple 头文件；修复系统未导出 SQLite 私有锁查询函数时的空指针调用。
- 保留已有金手指兼容、存档备份、容量预检、诊断和缓存优化。

验证范围：Python 分发/归档测试、macOS 生产后端 Swift 与金手指回归、真实文件描述符枚举测试、Xcode archive。发布前检查生成 IPA 内的许可全文、版本、无内置 SideStore，以及源码包的一致性。没有据此声称所有设备与游戏均已实测。

源码与构建：[本版本源码包](https://github.com/whodaregg/GameCase/releases/download/v1.0.20/GameCase-source.tar.gz)、[固定 tag](https://github.com/whodaregg/GameCase/tree/v1.0.20)、[构建与安装说明](https://github.com/whodaregg/GameCase/blob/v1.0.20/docs/BUILDING.md)。请保留这些资料并履行适用的再分发义务；第三方部分继续保留各自许可。

已知边界：历史 ElleKit 预编译兼容框架尚缺精确的源码提交记录，原 BSD 许可和可取得的来源已保留。旧 tag、旧安装包及其素材未由本次发布追溯替换。许可资料补充不授予任何原本没有的游戏美术使用权，也不是对所有司法辖区的法律合规保证。

## English

GameCase 1.0.20 — License materials, corresponding source and artwork cleanup

This fork is maintained by whodaregg; modification date: 2026-11-17. It is based on Tiaoge-tou/GameCase and LiveContainer and retains the original authors' and contributors' attribution. This is not an official upstream release.

- Adds “Licenses and Source Code” in settings. The IPA includes offline-readable AGPL, third-party licenses and copyright notices, including the external Apple ABI headers used by litehook.
- Provides GameCase-source.tar.gz, the complete main license, third-party notices and SHA256SUMS alongside the IPA. The source bundle includes this version's code, pinned litehook/OpenSSL materials, verified original OpenSSL 3.3.3 sources, and build/install instructions. Publication verifies that the IPA, source bundle and target commit have matching source trees.
- Verifies that the independent Zsign submodule used by Feather is MIT-licensed, retains the complete notices for both the original project and that submodule, and updates the provenance documentation.
- Removes two bundled game covers with unverified redistribution rights and related README game screenshots. Guest-provided and custom covers remain available. Store-cover retrieval is now a manual action in settings; importing games or browsing the library does not automatically access the store. Downloaded artwork and user-provided content still require the appropriate rights; the code license does not grant rights to game assets.
- Uses SDK F_GETPATH and a minimal current-process enumeration interface for background locked-file handling, removing the copied Apple headers that are no longer needed. Fixes a null-pointer call when the OS does not export the private SQLite lock-query function.
- Retains the existing cheat compatibility, save-backup, capacity-preflight, diagnostic and cache improvements.

Validation scope: Python distribution/archive tests, production-backend Swift and cheat regressions on macOS, real file-descriptor enumeration tests, and Xcode archive. Before publication, the generated IPA is checked for complete license texts, version information, absence of bundled SideStore, and consistency with the source bundle. This does not claim testing on every device or game.

Source and build materials: [source bundle for this version](https://github.com/whodaregg/GameCase/releases/download/v1.0.20/GameCase-source.tar.gz), [fixed tag](https://github.com/whodaregg/GameCase/tree/v1.0.20), [build and installation instructions](https://github.com/whodaregg/GameCase/blob/v1.0.20/docs/BUILDING.md). Retain these materials and comply with the applicable redistribution obligations; third-party components retain their respective licenses.

Known limitations: the inherited precompiled ElleKit compatibility framework still lacks a precise corresponding source-commit record. Its original BSD license and the available provenance have been retained. This release does not retroactively replace older tags, installation packages or their artwork. Adding license materials does not grant previously absent rights to game artwork or guarantee legal compliance in every jurisdiction.
